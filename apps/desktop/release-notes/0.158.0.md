- Typing in long notes is smoother: the editor no longer restyles the whole document on every keystroke.
- Saving a note in a big vault no longer reloads the tag tree and tag lists unless the note's tags changed, and the properties panel measures itself at most once per frame while you type.
- Long notes open faster: the editor sets itself up in one pass instead of redrawing the note once per extension.
- On a folder page, the folder's files sit in a compact Files section above its notes (two lines on Mac, three rows on iPhone, Show all for the rest) instead of pushing the notes down. A folder that only holds files lists them all and is no longer called empty on iPhone.
- Hide any property from every note: pick Hide in notes from the property's label (Show in notes on iPhone). Hidden fields fold under the panel's toggle and the choice is saved in the vault.
- Sync now pauses and asks before applying a change that would delete a large part of your vault.
