- Agents can draw canvas boards: `kore canvas <folder>` (MCP `draw_canvas`) turns a folder into a JSON Canvas board, with notes as cards, subfolders as groups and wiki links as arrows.
- The new kore-canvas skill teaches agents to write mind maps and moodboards that open in Kore and Obsidian.
- Haptics: one vocabulary on Mac and iPhone. On iPhone a long-press that selects a block gives a firmer tap, each block you add gives a tick, and picks, toggles, saves and deletes each feel different; navigation taps no longer vibrate.
- On Mac the trackpad clicks into place when you drag tabs, sidebar rows and editor blocks.
