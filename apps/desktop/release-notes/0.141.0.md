- Folder pages now include notes from subfolders by default. The option lives in a new Folder settings gear, and the filter is a search pill.
- Graph, Tasks and the iPhone tag and cell sheets use the same search and switch controls.
- Note cards on iPhone now show the note itself: tables as tables, tags as chips, tasks with their checkboxes. Each card is as tall as its note, the grid no longer moves while previews load, and a note that holds only a table or fields is never an empty card. Previews rebuild once on first open.
